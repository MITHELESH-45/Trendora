
# 🛒 Trendora – Full Stack Clothing E-Commerce Website  

Trendora is a **full-stack e-commerce platform** for clothing, built using the **MERN stack**.  
It provides a seamless shopping experience with product browsing, filtering, cart management, and secure checkout.  

---

## 🚀 Features  

- 🧾 **Product Catalog** – Browse clothing items with details  
- 🔍 **Search & Filters** – Find products by name, category, or price range  
- 🎨 **Variants Selection** – Choose sizes and other variants  
- 🛒 **Shopping Cart** – Add/remove items and adjust quantities  
- 💳 **Payment Integration** – Supports **Stripe**, **Razorpay**, and Cash on Delivery  
- 👨‍💻 **Admin Dashboard** – Manage products (add, edit, delete)  
- 🔐 **Authentication** – User login & signup with JWT and bcrypt  
- 📱 **Responsive UI** – Works across mobile, tablet, and desktop

## 🛠️ Tech Stack  

- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Payments:** Stripe API, Razorpay API  
- **Authentication:** JWT, bcrypt  
- **Deployment:** Vercel (Frontend & Backend), MongoDB Atlas
